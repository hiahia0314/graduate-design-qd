# A 股截面回测架构决策

1. **日频截面**：策略每天同时看到全部股票，满足横截面排序需要。
2. **收盘决策、次日开盘成交**：避免使用收盘后才知道的信息在当天成交。
3. **只做多**：目标权重在 0 到 1 之间，总和不超过 1，剩余部分为现金。
4. **目标外股票清仓**：未出现在目标组合中的持仓，其目标权重视为 0。
5. **收盘价计算股数**：组合层使用 T 日收盘资产和收盘价生成调仓数量。
6. **100 股一手**：目标股数向下取整到 100 股，符合 A 股常用交易单位。
7. **策略输出目标组合**：`TargetPortfolio` 代替逐股票买卖信号，更适合组合调仓。
8. **完整日截面输入**：`MarketSnapshot` 保存同一天全部股票的日线数据。
9. **使用 target_id 追踪**：追踪链为 `target_id → order_id → fill_id`，不保留 Signal 接口。
10. **账户快照**：组合层同时接收目标组合、账户状态和市场截面，职责更清楚。
11. **卖出优先**：次日开盘先卖后买，卖出资金可以参与同批调仓。
12. **买单按比例缩减**：跳空导致现金不足时同比例缩减，并保持 100 股整数倍。
13. **不允许负现金**：买入数量始终受实际可用现金约束。
14. **交易成本可配置**：保留佣金、最低佣金、印花税和滑点，首版默认都是 0。
15. **首版假设均可交易**：暂不处理停牌、涨跌停、ST、退市和公司行为，后续独立扩展。
16. **演示策略**：每天按 `close / open - 1` 排名，等权持有涨幅最高的两只股票。
17. **固定输出**：保存目标组合、订单、成交和每日权益，便于核查完整链路。


## 研究流程适配（2026-11-08）

以下内容更新前述最小演示版的约束：

- 正式研究对象为沪深300；现有中证500及当前成分股数据仅作开发样例，不作为历史沪深300研究数据。
- 优先完善回测底座和 A/B 信号接口，再接入因子检验、模型训练。
- 扩展第9条：保留目标组合驱动的交易接口，同时增加 `SelectionSignal`（B）和 `ExposureSignal`（A）。信号记录模型版本，目标组合记录两个 `signal_ids`，订单和成交继续通过 `target_id` 关联。原演示策略无需生成模型信号。
- `SignalStrategy` 接收三个显式提供器：选股信号、仓位信号、当日历史成分股集合。当前支持 Top-N 等权乘以总仓位，属于可替换的初始组合方式，不是研究结论。市场状态概率到仓位的映射由外部提供器完成。
- 同分股票按代码升序排序；候选股票取评分、当日成分股与当日行情的交集。信号日期必须与决策日一致；非有限评分、非法仓位和正仓位下无有效候选均报错。
- 日线输入日期必须严格递增，每个截面的股票代码及时间必须一致；CSV 重复行情报错，不再静默覆盖。
- 组合层验证目标权重、总仓位、行情价格及时间对齐。总权重允许 1e-12 的 Decimal 加总误差，不做自动归一化。

### 当前边界与下一步

已完成：基础输入防护、A/B 信号组合适配器、内存中的信号与目标追踪、回归测试。

待完成：历史成分股数据源及完整性校验、信号和实验配置持久化、独立风控、订单拒绝/取消记录、停牌和涨跌停处理、持仓可卖数量、公司行为及复权一致性、基准与绩效报告、模型训练时间划分及因子检验。

## 第二步实施与已确认规则

用户确认：未成交部分当日取消，后续由新信号重新调仓；A 信号缺失时报错，
纯选股实验显式使用固定仓位。

本轮新增：

- `HistoricalUniverse` 严格按日读取完整成分股快照，缺日及重复成员报错，不自动填充。
- `BacktestResult` 收集 A/B 信号；`export_result` 输出完整 JSON 和目标—信号关联表，保留空仓目标。
- `run_signal_demo.py` 提供完整可运行示例，仍使用演示数据，尚未接入真实沪深300历史数据。
- 撮合拒绝同日及未来日期订单；开盘方向限制通过行情字段显式输入，不使用当日完整行情推测。
- 订单处理结果记录 `filled` / `partial_cancelled` / `cancelled`、成交数量、取消数量及原因。
  资金不足时继续沿用按比例缩减及100股取整；受阻买单不参与资金预算。
- 期末未到撮合时点的订单作为 pending 单独输出。
- 记账层在变更账户前拒绝超额卖出、透支及非法成交价格、数量、费用。

后续仍需：真实历史数据与复权/公司行为处理、严格交易状态数据审核、板块差异化交易单位、
独立风控、可卖数量管理、基准与绩效指标、实验配置持久化、因子检验及训练时间隔离。
开盘限制字段是撮合扩展接口，并不代表已经实现全部A股交易规则。

## 第三步：静态风控与绩效评价

用户确认：权重削减部分留作现金；本轮只实现静态风控，最大回撤降仓及恢复规则稍后确定。

- 新增可插拔 `RiskControl`，默认不启用。`StaticRiskControl` 按禁入、持仓数、单股、行业
  顺序处理；不补选、不增配、不归一化。持仓数按目标权重排序，同权重按代码升序。
- `RiskDecision` 保存完整输入/输出目标和逐项调整，输出新目标ID，以 `parent_target_id`
  回链原始目标，保留 `signal_ids`。订单引用风控后的目标。
- `SecurityMetadata` 由时点数据提供；未知资格或行业不得绕过已启用规则。
- 保存每日实际持仓、市值、权重、行业与陈旧价格标志，区分目标合规与实际执行情况。
- `performance.json` 明确记录首日收盘基准、252交易日默认年化、日胜率、双边成交额折半
  换手、样本波动率、交易成本及基准累计收益差口径。不可计算的指标输出null。
- 两个演示入口继续使用虚构数据；新增命令行风控参数只在显式提供时启用。

本轮尚未解决真实历史成员、公司行为与复权记账、可卖数量和完整交易规则、动态回撤风控、
因子检验与模型训练隔离。绩效报告不将演示结果解释为真实沪深300研究结论。
