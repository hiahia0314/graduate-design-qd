# 沪深300实验数据

本目录仅保留2017—2025年日线实验需要的数据。历史成员按提供方数据直接采用，
不再以独立官方核验作为前置条件；这不代表源数据已全部验证正确。

## 实验划分

| 用途 | 区间 | 交易日 |
| --- | --- | ---: |
| 训练 | 2017—2021 | 1,217 |
| 验证调参 | 2022—2023 | 484 |
| 最终测试 | 2024—2025 | 485 |

共2,186个交易日、655,800条成员记录、596只历史成员股票。最终测试区间不得用于因子选择、
预处理拟合或调参。2016年不参与训练、验证、测试或特征预热。

年度行情只保留研究期曾入池证券及换股承接证券的可用记录。
每日买入候选必须由 `membership.parquet` 筛选，不能把年度行情全集当作当日成员。
日表保留的 `source_file` 是提供方原始路径标识，不代表文件仍在本目录。
日表保留原字段：`date` 为YYYYMMDD整数，`code` 为六位字符串。执行四价是
`open_raw/high_raw/low_raw/close_raw`；公司调整价和 `adjustment_factor` 供研究适配，
不能重复计入复权收益与现金分红。股票成交量单位为股、成交额为元。

## 当前可以做什么

基础价量面板准备入口为 `python prepare_dataset.py`，配置为 `config/dataset_splits.json`。
已实现年度字段转换、逐日成员覆盖检查、交易约束、独立公司行动归档、时间划分及哈希清单。
供应商输入保持不变；已准备成功的版本不允许原地覆盖，需要新输出路径/版本。

### 已确认的处理规则

- `YYYYMMDD` 显式解析为日期，六位代码转为 `.SH/.SZ`；不使用整数时间戳推断。
- 成员日原价或研究价缺失/无效，阻塞准备。非成员无效记录进入 `row_audit.parquet`，
  不进入对应的有效行情表；原始供应商文件仍保留全部记录。成员有效行情以每日成员表检验。
- 停牌记录保留估值价格并禁止双向成交。交易状态未知或限价未知也禁止成交。
  只有 `no_daily_limit.json` 明确列出的日期标记不限价；零限价不自动转为不限价。
  开盘价触及上限禁止买入、触及下限禁止卖出，不用当天最高/最低价决定开盘成交。
  日交易状态不保证开盘流动性；此限制是保守模拟假设。
- 执行表使用 `*_raw` 和 `volume_raw`；研究表使用供应商调整价及 `adjustment_factor`，
  不重新缩放为前复权，也不额外叠加现金分红。保留退池行情，样本资格由成员表单独控制。
- 公司行动原文件独立归档，不把分红表和送转表的重复现金字段相加，不假设现金选择权自动兑现。
  生成 `action_guards.parquet`。当前引擎尚无公司行动记账，涉及常规分红、送转、配股、
  换股、现金选择权和退市事件的持仓均受保护，在事件日（或其后的首个行情日）成交前后检查，
  触发后终止该次实验。登记日前持仓在登记日卖出也可能触发保守拦截。
  不清零资产、不强制卖出、不猜结算日期。未来实现相应记账后才能解除对应保护。
- 历史行业字段不进入研究特征或执行元数据。2016年不参与预热。
- 不生成训练标签，不执行预处理拟合或模型选择。最终测试仍要求显式授权访问。

### 输出与能力状态

`data/processed/csi300_2017_2025_v1/manifest.json` 记录输入/输出 SHA256、确认规则、
限制、分段日历和状态。`status=ready` / `panel_ready=true` 仅代表研究面板通过准备；
`labels_ready=false`、`backtest_ready=false` 分别表示标签未定义和完整公司行动记账未实现。
`backtest_mode=guarded_no_corporate_action_accounting` 允许未触发事件保护的受限实验。

每个 `train/validation/test` 目录包含：

- `execution_raw.parquet`：原价、成交量、ST原标记及可执行限制。
- `research_provider_adjusted.parquet`：供应商调整价、成交量额和复权因子。
- `membership.parquet`：实际每日成员和原始来源字段。
- `benchmark.parquet`：对应区间基准。

根目录还包含逐行审计、缺失成员报告、事件保护表、公司行动原文件和不限价依据。
使用 `PreparedSplit` 读取时核验相应文件哈希；`market_source()` 同时校验事件文件。
不要绕过该入口直接将原价表接入普通数据源，否则无法执行公司行动保护。

本次真实数据准备：1,302,856 条输入；655,800 条成员记录；成员行情无缺失；
94,810 条无效原价和94,812条无效研究价仅见于非成员；15,456 条停牌记录；
5条不限价映射。训练/验证/测试仍分别为1,217/484/485个交易日。

## 本次清理

删除了2016年度行情及专用补充包、原始压缩分卷、校验报告与公告附件、数据生成参考脚本、
接口探测、旧下载缓存、重复行情与旧数据准备状态。校验文档未另行备份到数据目录。
日历、每日成员、基准和日期明确的常规公司行动已限定为实验区间。
证券上市日期及跨边界事件的必要历史信息不因早于2017年而删除。
项目根目录的运行/下载脚本不属于本数据文件夹，未删除；旧下载和审计脚本可能依赖已删除的材料，
不再是当前数据集入口。演示与测试入口保留。

清理后数据约115 MiB，原目录约2.17 GiB，释放约2.06 GiB。
数据来自先前导入的沪深300最终整合包及AKShare基准，源记录保留自身来源字段和必要事件链接。
本报告替代此前数据目录说明，以本报告和当前配置为准。
