# 沪深300实验数据

本目录仅保留2017—2025年日线实验需要的数据。历史成员按提供方数据直接采用，
不再以独立官方核验作为前置条件；这不代表源数据已全部验证正确。

## 实验划分

| 用途 | 区间 | 交易日 |
| --- | --- | ---: |
| 训练 | 2017—2021 | 1,217 |
| 验证调参 | 2022—2023 | 484 |
| 最终测试 | 2024—2025 | 485 |

共2,186个交易日、655,800条成员记录、596只历史成员股票。最终测试区间不得用于因子选择、
预处理拟合或调参。2016年不参与训练、验证、测试或特征预热。

## 保留的数据

| 路径 | 内容与用途 |
| --- | --- |
| `market/daily/2017.parquet` 至 `2025.parquet` | 按年保存候选股票行情、复权因子、交易/ST状态、限价和原行业字段；包括退出指数后的行情，用于已有持仓估值与退出 |
| `market/benchmark.parquet` | 沪深300基准日线 |
| `market/trading_calendar.parquet` | 2017—2025年实验交易日历 |
| `market/constraints/no_daily_limit.json` | 已找到依据的5个不限价股票日期及来源；准备时映射到执行约束 |
| `universe/membership.parquet` | 每日真实股票池输入，日期、股票代码、权重及来源字段 |
| `universe/security_master_snapshot.parquet` | 证券主表快照；用于识别证券，不能当作历史时点行业/ST信息 |
| `corporate_actions/` | 历史源文件，仅保留为原始资料；当前准备与回测均不读取 |
| `samples/sample_bars.csv` | 6只虚构股票的框架演示和测试数据，不能用于研究结论 |

年度行情只保留研究期曾入池证券及换股承接证券的可用记录。
每日买入候选必须由 `membership.parquet` 筛选，不能把年度行情全集当作当日成员。
日表保留的 `source_file` 是提供方原始路径标识，不代表文件仍在本目录。
日表日期为YYYYMMDD整数，代码为六位字符串。原价、复权因子用于生成前复权OHLC。
成交量和成交额保留市场原统计单位，不用于虚构复权成交量或股份交收。

## 当前准备与运行口径

执行 `python prepare_dataset.py`，使用 `config/dataset_splits.json`，输出
`data/processed/csi300_2017_2025_v5_qfq`。已准备成功版本禁止原地覆盖。

- 前复权价＝供应商调整价÷全区间最后有效因子；各分段共用每只股票的锚点。
  保留供应商调整价，原价乘因子的差异仅审计（2018年11个停牌日），不重建。
- 研究、目标数量、成交和持仓估值全部使用前复权价；每笔买入为100个复权单位的整数倍。
- 历史成员按供应商每日成员表检查。成员行情缺失阻塞准备；非成员无效记录审计后省略。
- 停牌、交易状态未知或限价未知禁止成交。开盘触及上限禁买、触及下限禁卖；明确不限价的记录例外。
- 不读取、复制或加载公司行动文件，不生成事件保护表，不执行任何公司行动记账或阻塞。
- 无当日持仓行情沿用最后前复权收盘价；无行情订单取消；不生成自动兑付、换股或退市清算。
- 行业字段不进入研究特征或执行元数据；2016年不参与预热。
- 标签未定义，不执行模型训练；最终测试仍需显式授权。

各分段输出 `execution_qfq.parquet`、`research_qfq.parquet`、`membership.parquet`、`benchmark.parquet`。
根目录包含锚定因子、逐行审计、缺失成员报告和不限价依据，清单记录输入/输出SHA256。
`backtest_ready=true` 表示可运行当前简化前复权口径，不代表真实股份和现金交收模拟。
固定锚点包含全保留区间因子信息，不宣称为时点可得研究数据。
旧v1/v2/v3文件留存，当前读取器要求重新准备前复权版本。

## 本次清理

删除了2016年度行情及专用补充包、原始压缩分卷、校验报告与公告附件、数据生成参考脚本、
接口探测、旧下载缓存、重复行情与旧数据准备状态。校验文档未另行备份到数据目录。
日历、每日成员、基准和日期明确的常规公司行动已限定为实验区间。
证券上市日期及跨边界事件的必要历史信息不因早于2017年而删除。
项目根目录的运行/下载脚本不属于本数据文件夹，未删除；旧下载和审计脚本可能依赖已删除的材料，
不再是当前数据集入口。演示与测试入口保留。

清理后数据约115 MiB，原目录约2.17 GiB，释放约2.06 GiB。
数据来自先前导入的沪深300最终整合包及AKShare基准，源记录保留自身来源字段和必要事件链接。
本报告替代此前数据目录说明，以本报告和当前配置为准。

### 主板ST限价参考字段

年度面板可提供 `limit_reference_price_raw`：交易所当日涨跌停计算参考价（原价口径，除权除息日须相应调整）。
对当日 `is_st=1` 的沪深主板ST/*ST股票，适配器据此按2026-07-06前±5%、该日起±10%计算限价，四舍五入到分。
不限价清单优先；其他板块、非ST或缺少有效参考价仍采用供应商每日限价。不能用复权价或旧限价反推参考价。
既有2017—2025年源数据不因新规重写；缺少参考价时，后续2026年源数据须提供符合当日规则的限价。
